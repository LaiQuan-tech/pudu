# 丙午年普渡工作排程

和聖壇中元法會的行前與正日工作排程，手機閱讀用。

網址：https://laiquan-tech.github.io/pudu/

## 這是什麼

一頁純靜態網頁，開啟時由瀏覽器直接讀取 Google 試算表的 CSV 匯出，
所以**改試算表 → 重新整理網頁就更新**，不需要重新部署。

- 觀看者不需要登入任何帳號
- 本專案的原始碼不含任何個人資料，只有試算表 ID
- 有時間的工作排成時間軸，未指定時間的另歸「當日待辦」
- 可依日期、人員篩選，人員以不分大小寫歸戶
- 單日工作量 10 項以上自動標示為「正日」

## 維護

唯一的相依是試算表的共用設定必須維持「**知道連結的任何人 · 檢視者**」，
否則瀏覽器讀不到，頁面會顯示錯誤說明。

要換成別的試算表，改 `index.html` 開頭的 `SHEET_ID` 即可。
預期的欄位順序為：日期、時間、工作事項、人員、備註。
